# Header Portal Crest Design

## Scope

Replace the header block-emblem logo completely. Do not retain its `E` tile, two-row copy, divider, or `MINECRAFT NETWORK 03` label. The Home and loader wordmarks are unchanged.

## Design

- A code-native SVG diamond portal forms the standalone crest.
- Layered sapphire, cyan, and purple strokes create dimensional energy without raster assets.
- A lightning-shaped portal core supplies the focal point without using a letter monogram.
- `EDOLAS SG` appears in one horizontal fantasy-tech wordmark using the existing mono display font rather than the current pixel-label composition.
- Hover and keyboard focus produce one short portal sweep and restrained glow; no perpetual animation is introduced.
- The complete logo remains within the existing 80px header and scales down below 400px.

## Verification

- Source tests require the new SVG portal structure.
- Source tests reject every class from the superseded block-emblem design.
- Full tests, TypeScript, ESLint, and production build must pass.
